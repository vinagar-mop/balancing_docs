\chapter{System Transition Plans}
\label{loc:RequiredWork}
% \input{DIDINFO_Snippets/SDP/SDP_5.0.0_DIDINFO.tex}

The system transition plan is to implement all the code on the host machine and then transfer it through pipelines that is driven from updates on our get library. These updates will then be automatically transferred into the STM 32 board that is connected to the host machine. Once all the changes are done, then the house machine and the board will have the most updated software on it.

\section{Configuration Management Plans}
\label{loc:STP_ConfigMngtPlans}
% \input{DIDINFO_Snippets/SDP/SDP_5.1.0_DIDINFO.tex}

The configuration management system is primarily using the standard sprint. The standard Sprint will be a one week basis instead of a two week basis, and all of the implementations will be written thoroughly per task creation.
